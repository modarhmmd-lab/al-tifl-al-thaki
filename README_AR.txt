الطفل الذكي — مشروع Android أولي v0.1.1

مهم: هذه حزمة مصدر وليست APK جاهزاً. لم يتم بناء APK أو اختباره على هاتف حقيقي حتى الآن.

محتويات النسخة الحالية:
- تطبيق Android بسيط يفتح واجهة عربية محلية داخل WebView.
- ملفات الواجهة مضمّنة داخل التطبيق، لذلك تظهر الواجهة دون إنترنت.
- إعداد GitHub Actions محدث لبناء APK تجريبي (debug).

ما لا تحتويه النسخة بعد:
- لا توجد فيديوهات أطفال حقيقية مرفقة.
- لا يوجد نظام اشتراكات أو دفع أو حماية محتوى.
- العمل دون إنترنت يخص الواجهة فقط، وليس تشغيل فيديوهات غير مرفقة.
- ملف debug للتجربة فقط، وليس إصداراً تجارياً موقّعاً.

البناء السحابي:
1. يلزم رفع محتويات المشروع المستخرجة إلى مستودع GitHub جديد (وليس رفع ملف ZIP وحده).
2. يجب أن يظهر الملف .github/workflows/build-apk.yml داخل المستودع بهذا المسار.
3. افتح Actions ثم Build Android APK، واختر Run workflow.
4. بعد انتهاء العملية بنجاح، افتح تشغيل العملية ونزّل Artifact باسم al-tifl-al-thaki-debug-apk.
5. استخرج الملف app-debug.apk من الـ Artifact وانقله إلى هاتف Android للتثبيت.

إذا فشل البناء، افتح سجل العملية وانسخ رسالة الخطأ لمعالجتها.
